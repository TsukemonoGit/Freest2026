# バイト比較表作成コードの使い方

## 1. このコードでできること

`byte_csv_wide.py`は、解析結果の縦長CSVを、測定結果どうしを比較しやすい横長の表に変換するコードです。

元のCSVでは、1回の測定結果が次のように複数行へ分かれています。

| 測定順 | ラベル | 8ビット組位置 | LSB十六進数 |
| -----: | ------ | ------------: | ----------- |
|      1 | 1_bits |            18 | E0          |
|      1 | 1_bits |            19 | 1F          |
|      1 | 1_bits |            20 | 01          |
|      1 | 1_bits |            21 | FE          |

コードを実行すると、1回の測定結果が1行にまとまります。

| 測定順 | ラベル | 18バイト目 | 19バイト目 | 20バイト目 | 21バイト目 | 18/19補数 | 20/21補数 |
| -----: | ------ | ---------- | ---------- | ---------- | ---------- | --------- | --------- |
|      1 | 1_bits | E0         | 1F         | 01         | FE         | 一致      | 一致      |

この形式にすると、時間を変更したときに、各バイトの値がどのように変化するかを横方向に比較できます。

## 2. 準備するファイル

次の2ファイルを同じフォルダーに置きます。

- `byte_csv_wide.py`
- 比較したい元データのCSV

例：

```text
タイマー解析/
├─ byte_csv_wide.py
└─ 切りタイマー.csv
```

Python 3.10以降を使用します。このコードでは外部ライブラリのインストールは不要です。

## 3. 入力CSVに必要な列

通常は、これまでの比較コードが出力したCSVをそのまま使用できます。

最低限、次の列が必要です。

- `測定順`
- `ラベル`
- `8ビット組位置`
- 出力に使用する値の列

既定では`LSB十六進数`を使用するため、通常は次の見出しを含むCSVを入力します。

```text
測定順,ラベル,入力ファイル,8ビット組位置,受信順8ビット,MSB十進数,MSB十六進数,LSB十進数,LSB十六進数
```

次のようにMarkdownの記号が混じったデータも読み取れます。

- `**LSB十六進数**`
- `**0xE0**`
- `1\_bits`

出力時には、`**`、`\_`、16進数の`0x`を自動的に取り除きます。

## 4. 切りタイマーの18～21バイト目を比較する

### Windows PowerShellまたはコマンドプロンプト

対象のフォルダーで、次を実行します。

```powershell
python 04_byte_csv_wide.py "output切り_リセット抜き.csv" --positions 18-21 --sort natural-label --pair-check --output "切りタイマー比較.csv" --markdown "切りタイマー比較.md"
```

### macOSまたはLinux

```bash
python3 04_byte_csv_wide.py "output切り_リセット抜き.csv" --positions 18-21 --sort natural-label --pair-check --output "切りタイマー比較.csv" --markdown "切りタイマー比較.md"
```

実行すると、次の2ファイルが作成されます。

- `切りタイマー比較.csv`：ExcelやPowerPointへ貼り付けるための表
- `切りタイマー比較.md`：Markdown形式の表

## 5. 入りタイマーの22～25バイト目を比較する

対象位置だけを`22-25`へ変更します。

```powershell
py byte_csv_wide.py "入りタイマー.csv" --positions 22-25 --sort natural-label --pair-check --output "入りタイマー比較.csv" --markdown "入りタイマー比較.md"
```

同じコードを使い、任意のバイト位置を比較できます。

```powershell
py byte_csv_wide.py "元データ.csv" --positions 12 13 --output "12_13比較.csv"
```

`18-21`と`18 19 20 21`は、どちらも同じ指定です。

## 6. よく使うオプション

| オプション             | 内容                                              |
| ---------------------- | ------------------------------------------------- |
| `--positions 18-21`    | 比較するバイト位置を指定する。必須                |
| `--output 結果.csv`    | 出力するCSVの名前を指定する                       |
| `--markdown 結果.md`   | 同じ表をMarkdown形式でも保存する                  |
| `--sort natural-label` | `1_bits`、`2_bits`、`10_bits`を数値の順番で並べる |
| `--sort measurement`   | `測定順`の数値で並べる                            |
| `--sort input`         | 元CSVに登場した順番を保つ。既定値                 |
| `--pair-check`         | 指定位置を2個ずつ組にして、反転値か確認する       |
| `--include-file`       | 出力表に入力ファイル名も残す                      |
| `--hex-prefix`         | 16進数へ`0x`を付ける。指定しなければ付かない      |
| `--strict`             | 指定位置が1つでも欠けていた場合に処理を中止する   |

## 7. 表示する値を変更する

既定では、`LSB十六進数`を表示します。

```powershell
py byte_csv_wide.py "元データ.csv" --positions 18-21 --value lsb-hex --output "結果.csv"
```

`--value`では、次の値を選べます。

| 指定      | 使用する列          |
| --------- | ------------------- |
| `bits`    | 受信順8ビット       |
| `msb-dec` | MSB十進数           |
| `msb-hex` | MSB十六進数         |
| `lsb-dec` | LSB十進数           |
| `lsb-hex` | LSB十六進数。既定値 |

ビット列をそのまま横並びにしたい場合は、次のように実行します。

```powershell
py byte_csv_wide.py "切りタイマー.csv" --positions 18-21 --value bits --output "切りタイマー_ビット比較.csv"
```

## 8. 補数確認の見方

`--pair-check`を付けると、指定した位置を2個ずつ組にします。

`--positions 18-21`の場合は、次の組み合わせです。

- 18バイト目と19バイト目
- 20バイト目と21バイト目

2つの8ビット値がすべて反転した関係であれば、`一致`と表示します。

例：

- `E0`と`1F` → 一致
- `01`と`FE` → 一致
- `E0`と`20` → 不一致

この結果から、一方がデータ本体、もう一方が反転値として送信されている可能性を確認できます。ただし、この確認だけでは、どちらがデータ本体かまでは決まりません。

## 9. スライド用の表を作る場合

スライドでは入力ファイル名を省き、必要なバイトだけを残すと比較しやすくなります。そのため、通常は`--include-file`を付けずに実行します。

推奨する実行例は次のとおりです。

```powershell
py byte_csv_wide.py "切りタイマー.csv" --positions 18-21 --sort natural-label --pair-check --output "切りタイマー_スライド用.csv"
```

作成されたCSVをExcelで開き、必要な行をPowerPointへ表として貼り付けます。

## 10. エラーが出た場合

### 「必要な列がありません」と表示される

CSVの見出しを確認します。既定の`lsb-hex`を使用する場合は、`LSB十六進数`列が必要です。

### 「指定したバイト位置のデータがありません」と表示される

入力CSVに、`--positions`で指定した位置が含まれているか確認します。

切りタイマーなら通常は次の指定です。

```text
--positions 18-21
```

入りタイマーなら通常は次の指定です。

```text
--positions 22-25
```

### 表示順が10、11、12、1、2になってしまう

次のオプションを追加します。

```text
--sort natural-label
```

これにより、`1_bits`、`2_bits`、…、`10_bits`の順番に並びます。

### 一部の測定に「—」が表示される

その測定には、指定したバイト位置のデータがありません。欠けているデータがある場合に処理を中止したいときは、`--strict`を追加します。

## 11. ヘルプを表示する

使用できるオプションは、次のコマンドでも確認できます。

```powershell
py byte_csv_wide.py --help
```
