トランジスタの働き

GPIOの小さい電流で、大きい電流をON/OFFする — BC337-40BUのしくみ

第3章でIR LEDを駆動する際、GPIOから直接LEDへ電流を流す設計にせず、GPIOはBC337のBaseを操作するだけにしています。なぜGPIOで直接LEDを光らせないのか。このページでは、トランジスタの基本動作から、なぜ2kΩをBaseに入れるのかまでを整理する。

1. なぜGPIOで直接IR LEDを駆動しないのか

GPIOが安全に流せる電流には上限がある。一方、IR LEDを十分な明るさで光らせるには、GPIOの上限に近い、あるいは超える電流が必要になる場合がある。GPIOに過大な電流を流すと、マイコン側の破損につながる。

そこで、GPIOには「小さい電流でON/OFFを操作するだけ」の役割を持たせ、IR LEDへ流れる大きい電流は別の電源（VBUS）から別の経路で流す。この「小さい電流で大きい電流を制御する」という切り替え役を担うのがトランジスタである。

🔀トランジスタの役割

BC337-40BUは3本足の増幅素子で、Base（ベース）に流す小さい電流によって、Collector（コレクタ）とEmitter（エミッタ）の間に流れる大きい電流をON/OFFできる。

今回の回路では「増幅」というより、「GPIOで大きい電流をスイッチする」という使い方（ローサイドスイッチ）をしている。

2. 2つの電流経路 — Base側とCollector-Emitter側

BC337を使った回路には、独立した2つの電流経路がある。この2つを分けて考えることが理解の起点になる。

経路 電流の大きさ 流れる区間 役割
Base電流 小さい（約1mA程度） GPIO → 2kΩ → Base → Emitter → GND トランジスタをONにする「操作用」の電流
Collector-Emitter電流 大きい（IR LEDの駆動電流） VBUS → 330Ω → IR LED → Collector → Emitter → GND IR LEDを実際に光らせる「主電流」

Base側にわずかな電流を流すだけで、Collector-Emitter側の大きな電流経路が「開く」。GPIOはBase側の操作だけを担当し、IR LEDの主電流には一切関与しない。

3. なぜ「ローサイド」なのか

BC337はIR LEDとGNDの間に置かれている。つまり負荷（IR LED）の下流側（GND側）をON/OFFする配置になっている。この配置をローサイドスイッチと呼ぶ。

ローサイドスイッチとは
負荷（今回はIR LED）を電源側に固定し、GND側との接続をトランジスタで開閉する方式。負荷の上流側（電源側）を開閉する「ハイサイドスイッチ」もあるが、NPN型トランジスタ（BC337など）は構造上ローサイドで使うほうが単純な回路になりやすい。

4. Pin配置の確認

BC337-40BUは、平らな面を手前、足を下にして左からC-B-Eの順に並ぶ。Pin 1=Collector、Pin 2=Base、Pin 3=Emitterである。

Pin 名称 接続先
Pin 1 Collector（C） IR LEDのカソード側
Pin 2 Base（B） 2kΩ経由でGP18
Pin 3 Emitter（E） GND
⚠️ Pin配置を間違えると
C・B・Eを取り違えて接続すると、トランジスタが正しく動作しない、あるいは過大な電流が流れて破損する可能性がある。データシートで平らな面の向きとPin順を必ず確認する。

5. なぜ2kΩをBaseに入れるのか

Base-Emitter間は、ダイオードと同じような性質を持つ。電圧をかけるとほぼ一定の電圧（順電圧、BC337ではおおよそ0.6〜0.7V程度）を維持したまま、抵抗なしでは電流が際限なく増えようとする。GPIOをBaseへ直結すると、GPIOの出力電流の上限を超える電流が流れ、GPIOを壊す恐れがある。

なぜ2kΩなのか
Base-Emitter間はダイオードのように電流が流れるため、GPIOを直結すると流れすぎる。2kΩでおおむね1mA程度に抑え、GPIOは「スイッチを操作する小さい電流」だけを担当する。トランジスタは、この小さいBase電流に対して、Collector-Emitter側に十分大きな電流を流せる状態（ON状態）を作り出す。

5-1. Base電流の目安を計算する

GPIOの出力電圧を3.3V、Base-Emitter間の順電圧を約0.7Vとすると、2kΩにかかる電圧は次のようになる。

🔢計算

(3.3 - 0.7) ÷ 2000 ≒ 0.0013A

つまり約1.3mA。この程度の小さい電流でも、BC337はCollector-Emitter間に十分大きな電流（今回は330Ωで制限された約10mA級）を通す状態を作れる。

6. GPIOを流れる電流とIR LEDを流れる電流は別物

ここまでを整理すると、次の対比になる。

GPIOが担当する電流 IR LEDに流れる電流
経路 GPIO → 2kΩ → Base → Emitter → GND VBUS → 330Ω → IR LED → Collector → Emitter → GND
大きさ 約1.3mA 約10.3mA
電源 Pico（3.3V） VBUS（5V）

GPIOが流す電流とIR LEDが流す電流は、大きさも電源も経路もすべて別である。トランジスタは、この2つを分離しつつ、片方（Base）の状態でもう片方（Collector-Emitter）を制御する部品として機能する。
