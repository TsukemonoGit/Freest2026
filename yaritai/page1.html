やりたいことから始める 赤外線エアコンIoT (1/5)

第1章：目的の設定とマイコンの選定 — なぜ Pico 2 WH なのか

このシリーズは「部品リストが先にあって、それをどう配線するか」を説明するのではなく、「やりたいこと」から出発して、必要な機能を分解し、一つずつ部品を選び、回路を組んでいく思考プロセスを追います。

0. そもそも何がしたいのか

やりたいこと： 家のエアコンを、スマホや自動化ルールから操作したい。

制約：

  • エアコン自体を改造したくない（保証が切れるので）
  • 赤外線リモコンでしか操作できない機種
  • 電子工作はほぼ初心者。はんだ付けはまだ怖い
  • できれば手元にある ELEGOO Arduino スターターキットの部品を使いたい
  • 将来 Wi-Fi 経由でサーバーと連携したい

この「やりたいこと」を実現するために、どんな装置が必要か、頭の中で分解していきます。

図0：「やりたいこと」→「必要な機能」→「部品」への分解

1. 頭脳と通信手段を決める

1-1. マイコンに求める条件

まず、装置の「頭脳」となるマイコンを選びます。求める条件を整理します：

  1. 赤外線信号をマイクロ秒単位で扱える → 比較的高速な GPIO と、PWM や PIO などのハードウェア支援があると嬉しい
  2. 温度・湿度を読める → I²C や 1-Wire などのデジタル通信が使える
  3. 将来 Wi-Fi でサーバーと話したい → Wi-Fi 内蔵が理想。外付けモジュールは配線が増える
  4. 3.3V 系 → 最近のセンサーは 3.3V が主流。5V 系だと電圧変換が面倒
  5. MicroPython で書きたい → 文法が Python に近く、初心者にも敷居が低い
  6. 安価で入手しやすい → 失敗しても気軽に買い直せる

1-2. データシートを確認するとどうなっているか

Raspberry Pi Pico 2 W データシート（Raspberry Pi Ltd.）確認結果
  • GPIO 電圧：3.3V 固定（5V トレラントではない）
  • 電源ピン：3V3(OUT) Pin 36（3.3V 電源出力）、VBUS Pin 40（USB 給電時 約 5V）
  • Wi-Fi：CYW43439 内蔵（2.4GHz）
  • プロセッサ：RP2350（デュアルコア、PIO あり）
  • MicroPython 公式サポートあり

データシートを確認すると、GPIO は 3.3V 固定で 5V 入力に耐えないことが明確です。これは後の部品選定に大きく影響します。

選定：Raspberry Pi Pico 2 WH
理由：Wi-Fi 内蔵、3.3V 系、MicroPython 対応、PIO あり、安価。将来の第2部（サーバー連携）も見据えて WH（Wireless + ヘッダー付き）を選ぶ。

1-3. 電圧の世界観を固定する

Pico 2 WH を選んだ時点で、装置全体の電圧基準が 3.3V に決まります。これは非常に重要な分岐点です。

重要：Pico の GPIO は 3.3V 固定
VBUS ピンには USB 給電時に約 5V が来ますが、GPIO への入力信号は 3.3V を超えてはいけません。5V 信号を直接入れると壊れます。

この時点で、手元にある ELEGOO Arduino キットの部品を見直します。キットに入っている DHT11 や 5V 用 IR 受信モジュールは「そのまま」では使えません。電圧変換回路を追加するか、3.3V 対応の部品に置き換えるかの選択が生じます。

今回は「電圧変換を覚えるより、3.3V で動く部品を選ぶ方が早い」という判断で、不足部品のみ追加購入する方針を取ります。

2. エアコンの信号を「読む」仕組みを考える

2-1. エアコンはどうやってリモコンの信号を受け取っているか

エアコンのリモコンは、人の目には見えない赤外線（IR）LEDを高速で点滅させて信号を送っています。その点滅のパターン（どれだけ長く光る／消える）が「電源ON」「26℃」などの命令を表しています。

この信号を読むには、赤外線を電気信号に変換する受信モジュールが必要です。ただし、赤外線 LED はただ「光っている」だけではなく、38kHz という周波数で高速点滅（変調）しています。受信側はこの 38kHz の変調を検出して、「光が来ている／来ていない」をデジタル信号（HIGH/LOW）として出力してくれると便利です。

2-2. 受信モジュールの選定条件

  • 38kHz 帯の変調信号を復調できる
  • 3.3V で動作する（Pico に直結したい）
  • 出力が 3.3V レベル（Pico の GPIO に安全）
  • 入手しやすく、データシートが公開されている

これに当てはまるのが PL-IRM1838B です。次章でデータシートを確認し、配線を決めます。
